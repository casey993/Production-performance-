PRODUCTION PERFORMANCE BOARD PWA

Files to upload together to the root of your GitHub repository:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.svg
- icon-512.svg

GitHub Pages:
1. Create/open the repository for the performance board.
2. Upload all five files to the repository root.
3. Settings > Pages > Deploy from a branch > main > /(root).
4. Open the HTTPS Pages address on iPhone.
5. Use Share > Add to Home Screen.

The board auto-saves entries in that browser/device. Use Backup Data periodically if company records must be retained outside the device.

Included:
Throughput, OEE, Breakdown/Downtime, Yield, Manufacturing Cost Matrix,
OTD, Safety, Skill Matrix, Suggestion Details, Kaizen Before/After,
editable goals, automatic on-target/action status, trend charts, date/shift,
period snapshots, image attachments, backup/restore, print view, offline PWA.
